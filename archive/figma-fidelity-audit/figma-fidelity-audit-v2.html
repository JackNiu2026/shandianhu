根因分析(为什么"搬了没生效")

1
Figma CSS 是"考古地层"

index.css 历经 10+ 轮迭代,同一选择器被覆盖 5–8 次,最终有效值要靠人工追完整条 cascade——本次大部分偏差都是"最终覆盖层"漏同步

2
WXSS 与 Web CSS 的元素鸿沟

Taro 的 View/Text/Image 渲染为 view/text/image 原生组件,移植过来的 div(7 处)、img(19 处)、Text(1 处)元素选择器全部静默失效,且构建期无任何告警

3
弹窗组件 TSX 与 SCSS 脱节

Modals.tsx 是后写/重写的,JSX 用了裸 View/Text,没挂上移植 SCSS 所期待的语义类名,两边各自正确、合在一起失效

4
缺少视觉回归手段

没有截图对比 / 真机走查清单,样式静默失效难以被开发过程发现

  • 收敛设计稿 CSS(治本):把 1695 行"考古地层"计算成每个选择器一份最终声明的扁平样式表(可用浏览器 DevTools 或 PostCSS 脚本求值 cascade),此后小程序只跟单一事实源 diff,杜绝"漏跟最终层"复发
